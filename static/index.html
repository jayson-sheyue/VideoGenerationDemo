    试用示例

    Seed、计费标签、多轮状态

    Seed 与 labels 只在 Omni 1.2 上发送。多轮编辑需要上一条任务的 interaction id，服务端大约保留 7 天。

    无参考图时会补运镜与转场；有参考图时不改分镜原文，只追加动作说明。

    音频文件不能作为输入。公开 API 未开放音频参考（Cloud 博客写明需 allowlist）。对白、音效和音乐写在提示词里，由成片一起生成。

    Reference images

    可粘贴公网 URL，或直接从本地上传。浏览器读不到的地址会改由服务端下载，再上传到 GCS。

    Reference videos

    最多 3 段，用来锁人物、动作或风格，不当源片去剪辑。参考视频里的声音会被忽略。Gemini API 建议每段大约不超过 3 秒。
